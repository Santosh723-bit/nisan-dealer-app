# NISAN dealer app – price list updates

This repository holds `nisan-data.json`, the published price list for the NISAN ELECTRONICS dealer order app.

- Dealer apps download it automatically when they open with internet:
  https://santosh723-bit.github.io/nisan-dealer-app/nisan-data.json
- Prices and products inside the file are scrambled; it is not meant to be read directly.

## How to update
1. In the NISAN Master app: make your changes, then press **PUBLISH** and save `nisan-data.json`.
2. Here on GitHub: **Add file → Upload files**, drop the new `nisan-data.json`, then **Commit changes**.
3. Dealers get the new prices the next time they open the app with internet (GitHub can take 1–2 minutes to publish).

Do not upload the Master app or the Dealer app here: they contain readable prices and this repository is public.
